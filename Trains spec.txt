Instruction 1
===========================
I want a web based app that will allow me to plan a rail trip in the United Kingdom. The user will select:
1. A departure station
2. A destination station
3. An optional date. If no date is entered, use today's date.
4. An optional departure time. If no departure time is entered use the current time.
5. An optional arrival time. If no arrival time is entered then ignore this.

Notes:
1. You can not enter a departure and arrival time. Include one time entry with an option button for departure or arrival time.
2. When selecting the stations use a dropdown list that allows the user to select from a list of United Kingdom stations. This should be a search box and the dropdown list should be limited to entries that include the text entered.

When the user hits enter, the app will search for trains that meet this criteria and list the next five journeys.
If the user selects one of the journeys then the app will add the journey details to Google calendar. The user must be logged in to Google in the browser.

Each leg of the journey is added to the calendar separately. Departure and arrival for each leg are entered as separate calendar entries. The format of the entries will be:

Departure
Title: Depart <departure station name> p<platform number>
Location: the departure station
Note: Train details describing the service e.g. Merseyrail from Southport to Liverpool Central
Notification: 10 minutes

Arrival
Title: Apprive <arrival station name> p<platform number>
Location: the arrival station
Notification: 5 minutes
